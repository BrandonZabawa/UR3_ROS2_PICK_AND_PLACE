# Ideas for future work

A parking lot for anything new or interesting that comes up while working. Capturing an idea
here takes under a minute and ends the distraction; acting on it waits for the weekly shallow
block (see `PLANNING.md`, section 2).

## Rules

1. **Capture, don't act.** Mid-session, write one line in the Inbox below and return to the task.
2. **Triage every Sunday.** Each inbox item gets one outcome:
   - **Promote**: open an issue (Deliverable or Experiment form), link it here, move the line to Promoted.
   - **Park**: move to Parked with a reason and the earliest time it makes sense (e.g. "after HW-5").
   - **Drop**: delete it, or move it to Dropped with a one-line reason if it's worth remembering why.
3. **Make it testable when promoting.** Write the question, the metric, and what result would change your plan.
4. **Robot and concept.** Tag each idea with a robot ID and a concept-matrix row, so promoted
   ideas fill gaps in the matrix first.
